# 🍎 Omarchy for macOS (`omarchy-mac`)

> **Authentic Glass Acrylic Tiling Desktop Suite for macOS (Sonoma, Sequoia & Modern macOS)**

[![License: MIT](https://img.shields.io/badge/License-MIT-yellow.svg)](https://opensource.org/licenses/MIT)
[![Tiling WM](https://img.shields.io/badge/WM-AeroSpace-purple.svg)]()
[![Platform](https://img.shields.io/badge/platform-macOS%20Sonoma%20%7C%20Sequoia-000000.svg)]()

`omarchy-mac` brings the legendary **Omarchy Linux** tiling desktop aesthetic, acrylic glass status bars, dynamic theme switcher, and modal keybindings directly to macOS — requiring **zero SIP (System Integrity Protection) disabling**.

---

## ✨ Features

- 🍎 **SIP-Safe Tiling Window Manager**: Powered by AeroSpace for automatic i3/Hyprland-style window tiling and workspace management.
- 🔮 **Glass Acrylic Status Bar**: Sketchybar integration with space indicators, CPU/RAM monitoring, and battery metrics.
- 🌈 **Active Window Glow Borders**: Jankyborders active window accent highlight.
- 🎨 **22 Curated Omarchy Themes**: Tokyo Night, Catppuccin Mocha, Nord, Cyberpunk, Gruvbox, Dracula, Synthwave, and Everforest.
- 🚀 **Turnkey Installer**: Automated Homebrew installation script (`install.sh`).

---

## 🚀 Quick Start (macOS)

Open Terminal and run:

```bash
git clone https://github.com/apravint/omarchy-mac.git
cd omarchy-mac
chmod +x install.sh
./install.sh
```

## ⌨️ Keybindings Cheat Sheet

| Keybinding | Action |
| :--- | :--- |
| `Alt + Enter` | Launch Terminal |
| `Alt + H / J / K / L` | Focus window (Left / Down / Up / Right) |
| `Alt + Shift + H / J / K / L` | Move window position |
| `Alt + 1 .. 6` | Switch Workspace 1 - 6 |
| `Alt + Shift + 1 .. 6` | Send active window to Workspace 1 - 6 |
| `Alt + Space` | Toggle Floating / Tiling Mode |
| `Alt + Shift + Q` | Close active window |
| `Cmd + Alt + T` | Open Live Theme Switcher |
